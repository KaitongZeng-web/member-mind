# 腾讯生态可选连接设计（本版未实现写入）

核心 Skill 不要求注册、连接腾讯表格或 ima。用户首次使用直接处理本地文件。下述是后续适配器的设计契约，不代表产品已有接口或本环境已经连接。

## 何时询问

本地已生成并核对纪要/计划后，若用户需要团队协作或长期沉淀，可问一次：“是否将已核对结果同步到腾讯表格管理跟进，或写入 ima 作为可检索知识？也可以继续只保存本地文件。”

记录选择：未询问 / 仅本地 / 待连接 / 已连接 / 已失效。选仅本地后不在每轮打断；用户主动要求同步时再检查。已有授权且目标、内容明确时直接按授权执行。授权由宿主界面处理，不把密钥写进聊天、Skill 或工作目录。

## 挂载机制

Skill 本身不安装 MCP 服务。宿主发现已安装工具→读取真实工具描述和 schema→识别读取/创建/更新能力与权限→匹配适配器→执行。不得猜测诸如 create_ima_document 的工具名。

能力登记建议：provider、真实 tool_name、schema_version、read/write 能力、authorization_state、target_id、最近验证时间。无法发现、只读或接口不支持写入时返回明确状态，并提供本地 MD/CSV，不伪造成功。

| 环节 | 输入 | 输出标准 | 核对/失败处理 |
|---|---|---|---|
| 腾讯表格成员读取 | 用户指定表格/工作表、读取范围、真实连接权限 | 表头映射、稳定业务编号、来源定位、导入报告 | 同名不合并；冲突隔离；分页未完标 partial |
| 腾讯表格任务同步（待实现） | 已核对计划、目标表、字段映射、task_id、源版本、拟写入差异 | 每条任务远端记录 ID、版本、成功/失败回执、同步时间 | 首次确认目标及拟写内容；不覆盖未读取的人工变更；失败仅重试未成功项 |
| ima 知识写入（待实现） | 已核对纪要、简报事实、原文引用、目标知识库及用户允许的可见范围 | 文档 ID/链接、版本、写入内容摘要、回执 | 未核对草稿/推断/敏感联系方式默认不入库；字段取舍由用户决定 |
| 恢复/重试（待实现） | 本地成果 ID、内容 hash、远端回执 | 去重结果和差异清单 | 幂等键建议为目标+成果ID+版本；超时先查回执，不盲目重复创建 |

## 范围与数据边界

- 企业检索 → 候选证据；不等于会员资格、同意联系或自动建档。
- 腾讯表格 → 团队执行状态；本地任务完成不等于客户续费。
- ima → 经核对知识沉淀；写入成功需真实服务回执，不能用本地文件成功替代。
- 所有外发仅包含当前任务必要字段；姓名、电话等不随整张会员表自动发送。
- 当前交付的可运行范围：本地核心 + MCP 查询意图/候选归一化。腾讯表格/ima 仅此设计，等待真实工具和账号条件后再做适配与联调。
